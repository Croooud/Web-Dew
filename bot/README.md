# Приветствие бота

`worker.js` отвечает на `/start` и на любое сообщение: картинка `greeting.jpg` с текстом и кнопками
«Открыть страницу разработчика» (открывает мини-апп) и «Написать Ивану».

## Подключение (около 10 минут, без командной строки)

1. Зарегистрируйтесь на https://dash.cloudflare.com (бесплатно).
2. Workers & Pages → Create → Create Worker. Имя, например, `ivan-bot`. Нажмите Deploy.
3. Откройте воркер → Edit code. Удалите шаблон, вставьте содержимое `worker.js`, нажмите Deploy.
4. Settings → Variables and Secrets → добавьте два секрета (тип Secret):
   - `BOT_TOKEN` — токен бота из BotFather
   - `WEBHOOK_SECRET` — любая длинная строка из латиницы и цифр, например `Xk29aLmPq81ZvT04bn`
5. Скопируйте адрес воркера вида `https://ivan-bot.<ваш-аккаунт>.workers.dev`.
6. Откройте в браузере одну ссылку (подставьте свои значения), чтобы привязать бота к воркеру:

   `https://api.telegram.org/bot<BOT_TOKEN>/setWebhook?url=<АДРЕС_ВОРКЕРА>&secret_token=<WEBHOOK_SECRET>`

   Ответ должен быть `{"ok":true,...}`.
7. Напишите боту `/start` с другого аккаунта и проверьте, что пришло приветствие.

Токен бота не храните в коде и не отправляйте в чат: он даёт полный контроль над ботом.
Если токен засветился, выпустите новый: BotFather → `/revoke`.

## Что можно поменять

В начале `worker.js`: `GREETING` (текст), `APP_URL` (адрес мини-аппа), `CONTACT_URL`
(куда ведёт «Написать Ивану»), названия кнопок в `KEYBOARD`.
