# Web Dew — портфолио Telegram Mini App

Одностраничный Mini App: профиль, услуги, цены, шаблоны работ, контакты.

## Запуск
1. Settings → Pages → Branch `main`, папка `/ (root)`. Адрес: `https://croooud.github.io/Web-Dew/`.
2. В @BotFather: `/newbot`, затем `/newapp` (или Bot Settings → Menu Button) и укажите адрес выше.
3. Откройте бота в Telegram: кнопка «Обсудить проект» внизу станет родной MainButton.

## Что настраивать
- Статус доступности: `STATUS.state` (`open` или `busy`) в начале скрипта.
- Контакты и ссылки на сайты: блок `PROJECTS` и компонент `Contacts`.
